# AI Tool Usage Declaration

Required by SRS 1.8 #19.  Every use of an AI tool during development is recorded
here.  Note the distinction the SRS draws:

* Using a **Generative AI API inside the product** is a mandatory architectural
  requirement of this category.
* Using an **AI assistant to help write code** is permitted, but the code must be
  independently reviewed, modified where required, tested, debugged and understood
  by a named team member.  Anyone unable to explain a module may receive zero for it.

---

## A. Generative AI used *inside the application* (architectural requirement)

| Item | Value |
|---|---|
| Primary provider | Google Gemini (AI Studio, free tier) |
| Primary model | `gemini-2.5-flash` (pinned in `.env`) |
| Embeddings | `gemini-embedding-001`, reduced to 768 dimensions and L2-normalised |
| Fallback provider | Groq — `llama-3.3-70b-versatile` |
| Optional third fallback | OpenRouter free-tier model |
| Prompt templates | `prompt_templates/` — versioned, checksummed, registered in `prompt_versions` |
| Where it is used | Pipeline 1 only: classification, entity extraction, resolution steps, customer response, clarification questions, escalation notes |
| Where it is **not** used | Pipeline 2 (ground-truth validation), business rules, policy precedence, escalation enforcement, schema validation, comparison logic, security controls, audit logic |
| Failure behaviour | Retry is bounded by `LLM_MAX_RETRIES`, then failover Gemini → Groq → OpenRouter. If all fail, Pipeline 1 records the failure and Pipeline 2 decides alone. Nothing is fabricated. |
| Response cache | `llm_cache` stores **real** captured responses only, and only after they pass validation. It is never used to manufacture output a provider did not produce (SRS 1.8 #17). |

Earlier drafts named `gemini-2.0-flash` and `text-embedding-004`. Both return 404 on
the current API version, and `gemini-flash-latest` returned 503 during testing — which
is the argument against pinning a floating alias. The models above are the ones the
system was actually run against.

## C. Dataset generation

| Artefact | Method | Human review |
